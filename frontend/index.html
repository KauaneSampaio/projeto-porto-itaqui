Simulações

Clique para abrir

    Uma simulação é uma cópia do orçamento em que você troca os índices (IPCA, INPC, IGP-M) para responder perguntas como “e se a inflação subir?”.

    Premissas

    Este é o orçamento oficial (protegido por padrão).

    Para testar hipóteses sem mudar o oficial, crie uma simulação. Se você realmente precisa ajustar o orçamento oficial, clique em Liberar edição do oficial.

    Edição do orçamento oficial liberada: ao salvar, os índices e valores orçados dos meses abertos serão atualizados na base oficial e registrados nos logs de auditoria.
